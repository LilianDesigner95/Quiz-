# Quem fez isso? — MVP

Landing page mobile-first com quiz factual e links de fonte.

## Como testar
Abra `index.html` no navegador.

## Como publicar
Pode arrastar a pasta para o Netlify Drop ou subir o conteúdo em um repositório e conectar ao Netlify/Vercel.

## Estrutura
- Hero editorial
- Bloco de impacto sobre a pandemia
- 10 perguntas
- Feedback imediato
- Link da fonte em cada resposta
- Resultado final
- Compartilhamento via Web Share API
- Biblioteca de fontes

## Observação editorial
As perguntas foram escritas para distinguir fatos documentados, recomendações de CPI e resultados judiciais. Não troque “recomendação de indiciamento” por “condenação”.
